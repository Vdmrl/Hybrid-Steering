# Experiment design: concept-aligned rank slots

## Короткий ответ

Да, это реализуемо.

Для каждого концепта сохраняем отдельную rank-1 матрицу:

\[
B_i = u_i v_i^\top,
\qquad
S_t = S_t^{free} + \sum_i c_i B_i.
\]

Здесь \(B_i\) — именованный слот концепта, а \(c_i\) — его независимо
управляемая сила.

Если один раз сложить все \(B_i\) и дальше дать GDN свободно обновлять
состояние, это эквивалентно текущему additive steering. Более глубокий вариант
появляется только тогда, когда после каждого recurrent update мы отдельно
восстанавливаем или замораживаем коэффициенты \(c_i\). Тогда свободная часть
состояния продолжает меняться, а выбранные концепты сохраняются.

Стандартный SVD суммы использовать нельзя как источник семантических слотов:
его компоненты могут смешать несколько концептов. Идентичность слота задаётся
тем, что мы сохраняем исходную пару \(u_i,v_i\) каждого концепта.

## Гипотеза

Четыре concept-aligned rank-1 слота можно независимо закреплять в recurrent
state GDN. Выключение одного слота должно ослаблять только соответствующий
признак, не разрушая остальные признаки и качество ответа.

## Основной набор признаков

1. Principled candor.
2. Concrete language.
3. Optimism.
4. French language.

Joy остаётся пятым стресс-тестом после успешного четырёхслотового запуска.

## Проверка пересечения слотов

Отдельные rank-1 матрицы не обязаны быть ортогональными. До генерации считаем
Gram matrix:

\[
G_{ij} = \langle B_i,B_j\rangle_F.
\]

Сохраняем pairwise cosine, effective rank и condition number. Если направления
сильно пересекаются, сравниваем два варианта:

- исходные concept-aligned слоты;
- QR-ортогонализованные слоты.

Ортогонализованный вариант является абляцией: он уменьшает численное
пересечение, но может изменить семантику концепта.

## Интервенция

После обычного обновления GDN получаем \(S_t^{raw}\), затем восстанавливаем
целевые коэффициенты слотов:

\[
S_t =
S_t^{raw}
+ \sum_i (c_i^\* - \hat c_i(S_t^{raw})) B_i.
\]

Для неортогональных \(B_i\) коэффициенты \(\hat c_i\) оцениваются совместно
через Gram matrix, а не независимыми скалярными произведениями.

Это сохраняет только выбранные компоненты. Остальная часть recurrent state
остаётся доступной модели.

## Минимальная матрица условий

| Условие | Что проверяет |
|---|---|
| Baseline | Поведение без вмешательства |
| Add once after prefill | Текущий additive rank-1 baseline |
| Slot init after prefill | Контроль: при тех же коэффициентах должен совпасть с add-once в начале |
| Slot clamp every token | Сохраняются ли четыре концепта на всей генерации |
| Orthogonal slot clamp | Помогает ли разделение подпространств |
| Clamp minus one slot ×4 | Можно ли независимо выключить каждый концепт |

Первый запуск: 32 dev и 128 test prompts. После выбора реализации —
подтверждающий запуск на 256 test prompts.

## Метрики

- expected score каждого активного признака;
- all-active \(score \ge 4\);
- minimum active expected score;
- answer quality;
- сохранение эффекта по позиции токена;
- cross-talk: изменение остальных признаков при выключении одного слота;
- effective rank и pairwise cosine слотов.

## Критерий успеха

Эксперимент считается успешным, если:

1. slot clamp сохраняет признаки дольше, чем add-once;
2. выключение одного слота заметно снижает только его собственный score;
3. остальные feature scores меняются мало;
4. answer quality не падает более чем на 0.25 относительно baseline;
5. результат повторяется на независимых test prompts.

## Что не входит в первый запуск

- дообучение модели;
- изменение весов GDN;
- резервирование физических координат матрицы;
- одновременная проверка больше пяти концептов.

Если inference-only вариант работает, следующий этап — SFT/representation
finetuning, где slot basis заморожен, а модель учится обновлять только
\(S_t^{free}\). Ближайшие аналоги по идее — LoReFT, CS-ReFT и композиция
low-rank adapters, но concept slots в recurrent state GDN остаются отдельной
экспериментальной гипотезой.

## Связь с Experiment 4

Experiment 4 проверяет обычное сложение rank-1/rank-4 направлений и
RSS-нормализацию. Он не реализует сохраняемые concept slots и не должен
изменяться во время текущего запуска. Этот дизайн является отдельным
последующим экспериментом.
