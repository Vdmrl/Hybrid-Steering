# Syntax/discourse singleton screen

Exploratory GPU-only screen of three candidate directions:

- short atomic sentences vs complex joined sentences;
- explicit logical connectives vs implicit transitions;
- rhetorical questions vs declarative prose.

Each feature uses 16 locally rewritten content-matched pairs and four common
held-out prompts. The screen checks rank 1 and rank 4 at alpha 2 and 4. It does
not run composition or spend Judge API credits.
